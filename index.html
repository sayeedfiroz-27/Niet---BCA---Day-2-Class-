2. Relational Operators

Project PurposeIs project ka purpose learner ko ye samjhana hai ki Python ke basic topics alag-alag theory nahi hain. Ye sab milkar ek real program banate hain jo user se marks leta hai, calculation karta hai, decision leta hai, aur final report print karta hai.
Python Code
student_name = "Rahul"
subjects = ["Maths", "English", "Science", "Computer", "Hindi"]
marks_list = []

for subject in subjects:
    marks = int(input("Enter marks for " + subject + ": "))
    marks_list.append(marks)

total_marks = 0
for marks in marks_list:
    total_marks += marks

maximum_marks = len(subjects) * 100
percentage = (total_marks / maximum_marks) * 100

if percentage >= 90:
    grade = "A+"
elif percentage >= 75:
    grade = "A"
elif percentage >= 60:
    grade = "B"
elif percentage >= 35:
    grade = "C"
else:
    grade = "Fail"

print("Student Name:", student_name)
print("Total Marks:", total_marks)
print("Percentage:", percentage)
print("Grade:", grade)
